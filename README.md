# QStory Plugin Manager

QStory 脚本管理器，用于浏览、下载和管理 QStory 在线脚本。

注: 使用脚本你需要为自己所加载脚本负责 自行辨别脚本是否包含了危险功能

## 功能特性

- 📋 **脚本浏览** - 浏览所有在线脚本，支持按标签筛选
- 🔍 **搜索功能** - 快速搜索脚本名称和作者
- 📸 **脚本预览** - 查看脚本图标和预览图
- ⬇️ **一键下载** - 直接下载脚本到本地
- 📱 **现代 UI** - 基于 Miuix KMP 的简洁美观界面

## 使用说明

1. 首次打开应用会自动加载在线脚本列表
2. 点击脚本卡片进入详情页
3. 在详情页可以查看脚本信息、预览图
4. 点击"下载"按钮将脚本保存到本地

## 脚本存储位置

下载的脚本保存在：
```
/Download/QStoryPlugin/
```
