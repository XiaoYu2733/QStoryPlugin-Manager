# QStory Plugin Manager

QStory 脚本管理器，用于浏览、下载和管理 QStory 在线脚本。

> 使用脚本请自行辨别脚本是否包含危险功能，对所加载的脚本负责。

## 功能特性

- **双界面风格** — 支持 Miuix 和 Material 3 两种界面风格，可在设置中切换
- **脚本浏览** — 浏览所有在线脚本，支持按状态（待审核/已通过/未通过）和标签筛选
- **搜索功能** — 快速搜索脚本名称和作者
- **脚本详情** — 查看脚本图标、预览图、简介等信息
- **AI 评审** — 查看脚本的 AI 合规评审结果、风险等级和改进建议
- **一键下载** — 直接下载脚本到本地
- **平台统计** — 查看脚本数量、审核情况、AI 评审、用户互动等统计数据
- **动态主题** — 基于 Material You / Monet 取色的动态配色方案
- **主题定制** — 支持多种调色板风格、强调色自定义、界面缩放等

## 使用说明

1. 首次打开应用会自动加载在线脚本列表
2. 通过顶部搜索框和下拉菜单筛选脚本
3. 点击脚本卡片进入详情页，查看简介、AI 评审、预览图
4. 点击下载按钮将脚本保存到本地
5. 切换底部标签页查看平台统计数据
6. 在设置中切换界面风格、调整主题等

## 脚本存储位置

下载的脚本保存在：
```
/Download/QStoryPlugin/
```
